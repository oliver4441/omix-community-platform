# Omix Community Platform

A Discord-style chat PWA built as a standalone frontend application. 

## Structure
- PWA setup in `manifest.json` and `sw.js`
- React components in `components/`
- Mock state in `utils/store.js`
- Main entry point in `app.js`

## Note
Ensure this README is updated as new features (e.g. Firebase Auth, Firestore real-time sync, WebRTC) are added.
